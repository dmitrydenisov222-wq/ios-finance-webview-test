# iOS Developer Test — Finance & WebView App

Тестовое на позицию iOS Developer: приложение для учёта финансов и WebView модуль с динамической загрузкой контента.

---

## 📋 Требования

- iOS 15.1+
- Xcode 15.0+
- Swift 5.9+

---

## 🏗 Архитектура

Приложение состоит из трёх основных модулей:

### 1. Splash & Routing
- **`SplashView`**: экран загрузки с анимацией.
- **`AppState`**: глобальное состояние, определяющее стартовый модуль (`module1` / `module2`).
- **Логика выбора**:
  - При первом запуске загружается JSON с сервера, проверяется валидность ссылки:
    - Валидная → сохраняется и открывается **модуль 2** (WebView).
    - Ошибка сети/парсинга/невалидная ссылка → открывается **модуль 1** (финансы).
  - При последующих запусках используется сохранённое решение (без повторных проверок).

### 2. Модуль 1: Онбординг + Учёт финансов
- **`OnboardingView`**: показывается один раз, при первом открытии модуля 1.
- **`FinanceMainView`**: экран учёта доходов/расходов:
  - Баланс и список операций.
  - Простой линейный график динамики баланса.
  - Форма добавления операции.
  - Сохранение данных в `UserDefaults` (JSON).

### 3. Модуль 2: WebView
- **`WebViewContainer`** + **`WebViewController`**:
  - Открытие ссылки из JSON.
  - Сохранение последней посещённой страницы.
  - Сохранение логина (cookies через `WKWebsiteDataStore.default()`).
  - Жесты навигации:
    - Свайп вправо → назад.
    - Свайп влево → вперёд.
    - Свайп вниз → перезагрузка страницы.
  - Открытие дочерних окон (`target="_blank"`) в текущем WebView.
  - Поддержка landscape ориентации.
  - Доступ к камере (разрешения в `Info.plist`).
  - Поддержка HTTP трафика (`Info.plist`).

## 📦 Технологии

- **SwiftUI**: UI для модулей 1, 2, Splash, онбординга.
- **UIKit + WKWebView**: модуль WebView с кастомными жестами и делегатами.
- **Combine**: `ObservableObject` для `AppState` и `OnboardingState`.
- **UserDefaults**: сохранение состояния (выбор модуля, онбординг, финансы, последний URL).
- **URLSession + JSONDecoder**: загрузка и парсинг remote config.
